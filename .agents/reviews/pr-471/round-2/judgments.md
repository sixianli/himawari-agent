# PR 471 第 2 轮复核：逐条判断

- D1 成立，会出错，中高。场景改成显式字段 `webkitReports`，WebKit 上四种情况都断言：前三种必须报、卸载前已发出的请求必须不报（`PAGE_ERROR_FILTER_WEBKIT_BEHAVIOR_CHANGED`）。三引擎各 5 次通过。
- D2 成立，会出错，低。I-97 门槛一列把“地址不带端口时不放过”挪到单测名下。
- D3 成立，会出错，低。正则加上 `prependOnceListener`，抽成常量，新增正向五种写法、反向三种写法（含 `waitForEvent`）的单测。
- D4 成立，会出错，低。“一个端口只对应一种协议”的说法撤回；I-97 写明同主机同端口、协议不同的报错仍会被放过，以及夹具都是 http 随机端口所以不会出现。WebKit 报错不带协议，做不到更严。
- D5 成立，会出错，低。关闭时 `closeAllConnections()`，慢请求在连接关闭时清掉计时器；用例耗时从约 3 秒降到不到 2 秒。
- 场景名字符串判断改成显式字段（`sameOrigin`、`expectedHost`、`webkitReports`），属可以更好，顺手改了。
- “断网阶段”措辞改为“最后汇总时放过的断网报错”。
- 关于 D1、D6：模型读不到第 1 轮记录目录，没有给出意见。
