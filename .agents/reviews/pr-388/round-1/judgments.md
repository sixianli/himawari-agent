# PR 388 第 1 轮逐条判断

- **ds-1**（中）「去重路径会让 storedFor 的防重放兜底失效」：成立。同一组参数已有规则时，生效的是那一条，`storedFor` 按本提议的编号查不到；标记再丢掉，撤销后重放就会新建规则。修法：服务在内存里记下已生效的提议，保留到确认状态过期（签名密钥每进程随机，旧确认只能在这个进程、10 分钟内重放），这一处覆盖所有路径；标记和 `storedFor` 留作第二、三道。新用例「reuses an existing rule…」，去掉内存记录后失败。ADR「进程中断」的措辞也改了。
- **ds-2**（低）「规则已生效后标记写失败，却返回没有生效」：成立。标记写不进去时记诊断日志、仍回「已生效」；新用例「reports a rule as active when only the marker could not be written」，改回抛错后失败。
- **ds-3**（低）「外部规则记忆被归为整理记忆」：成立。记忆页和来源报表把 `memory:rule:mcp:` 归为外部；报表测试三处前缀一致性检查加上它，计数用例加一条。P2-3 对话里的规则类记忆仍是原分类（不在本 PR 范围）。
- **ds-4 / glm-1**（低）「错误提示与校验不一致」：成立。文字改为「每项最多 64 字（phrases、excludePhrases 每项至少 2 字）」，参数不合法用例加 1 个字的词语。U+2028 这类分隔符能通过 P2-3 的解析器，是 P2-3 的校验范围，不在这里改。
- **ds-5**「就绪检查用记忆写入器」：不成立。`McpWriteAccess` 里 `proposals` 和 `rules` 都是必填，类型上不会缺；就绪条件（记忆册有世代）对规则也一样适用，因为 `#activate` 要写规则类记忆。
- **ds-6**「预览回放可被反复触发」：可以更好，不改。写令牌每分钟限 30 次，回放只读最近的已判断邮件；缓存要在状态里放回放结果或改 P2-3 的 create，收益小。列给 Andy。
- **ds-7**（低）「去重路径不会更新来源」：成立（文档）。ADR 决定 3 写明复用的规则保留原来源和记忆。
- **glm-2 / glm-3 / glm-4**：可以更好，按 Andy「可以更好就改」已补：标记写失败用例；键序和列表顺序不同算同一提议；同参数复用已有规则的用例。`accept` 里两个防御性抛错碰不到（create 标推断必存提议、confirm 必返回规则编号），不补。
- **glm-6**：信息，同 ds-5。
