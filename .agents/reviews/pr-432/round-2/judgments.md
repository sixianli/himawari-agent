# PR 432 第 2 轮判断

复核的是第 1 轮之后的增量。模型确认本 PR 不碰任何发给模型的内容。

## 会出错
- r2（中高）成立：10 个“已声明未安装”的操作原先登记在 `operations` 里，会连带压住后端、调用方、测试缺失的报错。已改：`ci/operations-pending.json` 新增 `notInstalled` 一节，只用来豁免“已声明未安装”，不压 `OPERATION_INCOMPLETE`；条目一旦装进已安装清单，报 `OPERATION_NOT_INSTALLED_BUT_INSTALLED` 要求移出。新增用例：未安装条目不挡缺实现、装好后要求移出。
- r4（低）成立：存在性判断只认冒号，解析却认冒号和等号。两处统一为 `[:=]`，有用例。
- r5（低）成立：清单切分只认行首 `id:`。改为认任意位置的 `id:`，有内联写法用例。
- r7（低，推测）成立：路由分支解析前先去掉两个安装数组的内容，防止悬挂谓词配到数组里的 `options.X`。新用例在去掉这一步后失败（已验证）。
