# PR 466 第 2 轮作者说明
目标不变：给 iOS 第 11 批原生页三项网关能力（规则引用被取代标记、文件列表、登录设备），数据和网页同一份，不改表。
第 1 轮后的改动：
1. 已经退出的设备再发一次退出，先返回 replayed:true，不再要求最近验证；当前设备仍不能退；找不到的设备返回 404。
2. 取代链最多走 8 步，超过或成环返回 null。
3. files.list.snapshot 的 contentPath 上限放到 512，容纳 URL 编码后最长 128 字符的 id。
4. 两个未装进生产链的网关适配器也把 query 的第二个参数转交下去。
5. 网页规则测试夹具补上两个新字段，修好 control-center 的类型检查。
有意为之、不再改的两点：规则引用和 PR 429 一样只给模型看得见的记忆出引用；同主人但不同 agent 的记忆不给引用，和取代链的检查一致。网页撤销路由没有“不能退当前设备”的守卫是原有行为，不在本 PR 改。
做法只是参考，若你认为有更好的做法请提出。
