# PR 466 第 5 轮作者说明（整份复核）
目标：给 iOS 第 11 批原生页三项网关能力，数据和网页同一份设备和文件记录，不改表，不碰发给模型的内容。
1. 规则快照加 quoteSuperseded、quoteLatestMemoryId：来源记忆仍在用但已被取代时照样给引用并标明，沿 supersededBy 链找最新那条（最多 8 步；仍在用、模型看得见、同一主人和 agent 才给 id，否则 null）；归档的不标。
2. files.list.read/snapshot：包一层 ThreadArtifactStorePort.list，按时间倒序分页，按类型、来源筛选；控制层核对登录信息和 scope；坏 cursor 返回 400；文件名截到 256、媒体类型截到 128，控制字符换成 U+FFFD；contentPath 沿用网页会话的下载路由（上限 512）。
3. login.devices.read/snapshot、login.device.revoke：列出主人仍在用的登录设备（按最近使用从新到旧）并标出当前这台；退出别的设备要最近验证过身份，不能退出当前这台，找不到 404，已退出的重发返回 replayed；控制层核对登录信息里的主人和 scope 的主人、agent。GatewayV2ReadModelPort.query 加了可选的第二个参数（登录信息），各层原样转交。
前几轮的复核记录在 .agents/reviews/pr-466/ 下。有意不改的：设备列表不分页（网页同样不分页）；撤销不写审计（网页同样没有）；网页撤销路由允许退出当前设备（网页按钮会接着登出）。
做法只是参考，若你认为有更好的做法请提出。
