# PR 466 作者说明
目标：给 iOS 第 11 批原生页三项网关能力，数据和网页同一份，不改表。
1. 规则快照加 quoteSuperseded、quoteLatestMemoryId：来源记忆仍在用但已被取代时照样给引用并标明，沿 supersededBy 链找最新那条（仍在用、主人看得到才给 id，否则 null）；归档的不标。
2. files.list.read/snapshot：包一层 ThreadArtifactStorePort.list，按时间倒序分页，按类型、来源筛选；contentPath 沿用网页会话的下载路由。
3. login.devices.read/snapshot、login.device.revoke：列出主人仍在用的登录设备并标出当前这台；退出别的设备要最近验证过身份，不能退出当前这台。查询要知道是哪台设备在问，所以给 GatewayV2ReadModelPort.query 加了可选的第二个参数（登录信息），由 AgentGatewayV2Service 和治理层转交。
手机的设备签名下载口不在本 PR，等设备签名校验（另一个 PR）合并后再加。做法只是参考，若你认为有更好的做法请提出。
