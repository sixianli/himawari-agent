# PR 466 第 3 轮作者说明
目标不变：给 iOS 第 11 批原生页三项网关能力（规则引用被取代标记、文件列表、登录设备），数据和网页同一份，不改表。
上一轮之后的改动：
1. 第 2 轮的 5 条低严重度意见只补了测试（排序、404、context 转交、另一 agent、contentPath 边界）。
2. 文件列表的分页 cursor 字符合法但解不开时，返回 400（请求不合法），不再是通用的 409。
3. 登录设备的查询和撤销在控制层自己核对 scope.agentId，不只靠外层访问策略；补了控制层单元测试。
没有改的：网页端撤销设备路由允许退出当前这台，是有意的（网页“退出”按钮对当前设备会接着登出），网关这边仍不允许。规则引用只给模型看得见的记忆，restricted 级别本来就不能存成记忆，所以和“主人看得到”没有实际差别。
做法只是参考，若你认为有更好的做法请提出。
