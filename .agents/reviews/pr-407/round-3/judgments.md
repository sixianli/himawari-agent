# 第 3 轮判断

- r3-1（不成立）：行消失的其他原因是线程、主人或 Agent 被删除，那时这一轮本来就不用再存；放弃路径在保存循环之后才删行，不在循环里；生产只有一个实例，同一轮由 #busy 挡住。找不到“行消失而本该存的记忆没存”的输入。
- r3-2（成立，低，已修）：提交回包丢失时补发缓冲的审计，新测试在旧代码上失败。
- r3-3、r3-4（成立，低，已修）：审计逐条兜底；超时值在启动工作线程之前校验，新测试断言 SqliteExecutionContext.start 没被调用，旧代码上失败。
- r3-5、r3-6（成立，低，已改 ADR 0222）。
- r3-7（不成立）：这是复核材料里的说法，仓库里的 ADR 已按代码写（范围外读不等待）。
- r3-8（成立，低，已修）：读队列失败时不再重试，保留队列行。
