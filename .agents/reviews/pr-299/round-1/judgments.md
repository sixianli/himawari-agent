# 第 1 轮复核：线程逐条判断

复核提交 `65b2d9f0`（合并最新 main 之后），基线 `9f759313`（当时的 main）。两个模型都经 Magpie 跑：DeepSeek 一次跑成；GLM 第一次没跑起来（`wrap-up-time`，0 步，花 0.0004 美元），用 `--round 1` 重跑成功。本轮累计 0.5111 美元（含两次 GLM 失败的尝试与成功的一次）。

## 会出错——中、高（已改，需再复核一轮）

| 意见 | 判断和改法 |
|---|---|
| 还原表是从含 JSON 转义的提示文本建的，主人说的密码含引号、反斜杠、换行时，还原出的值带反斜杠（DeepSeek 第 5 条，GLM 第 4 条） | 成立。用探针对真实记忆整理提示实测：密码 `ab"cd` 在表里是 `ab\"cd`。`placeholderTable` 新增 `jsonEmbedded`：表建好后把值按 JSON 字符串解码（编号仍按转义后的值算，和出口遮盖一致）；记忆整理和对话标题都传。新增用例：记忆整理里含 `"` 和 `\` 的密码逐字节存下；还原单测里含引号、反斜杠、换行。反向验证：把 `jsonEmbedded` 关掉，记忆用例失败 |

## 会出错——低（已改）

| 严重度 | 意见 | 改法 |
|---|---|---|
| 低（模型标中高） | “还原不了的占位符不存”没有实现，测试名与断言不符（DeepSeek 第 2 条，GLM 第 1 条） | 行为不变：还原不了的占位符原样保留，这是方案 v3 和 Andy 已接受的代价。错的是测试名和空洞的断言，改成“原样保留，不编造值”，断言存下的正是占位符 |
| 低（模型标高） | 证件号测试名说“主人要求记住就存原文”，实际靠测试里模型标 private 才成立（DeepSeek 第 1 条） | 代码、提示词和方案 v3 一致（模型标 restricted 就丢弃）。测试名改成“模型判为 private 时照存”。提示词是否还要模型别记凭据，列给 Andy |
| 低（模型标中） | 重建占位符表没带固定提示词白名单（DeepSeek 第 4 条） | 实测：不带白名单时表里多出 `1000`（固定提示词里的数字）。`placeholderTable` 新增 `trusted`，两处调用都传 `TRUSTED_PROMPT_TEXTS`；新增单测 |
| 低（模型标中） | 生产装配的 `externalTag` 接线没有测试，断了没有用例失败（GLM 第 2 条） | 把两处 `externalTag` 改成必填，删掉装配里的那行类型检查就失败（实测 tsc 报 `externalTag` 缺失）；顺手删掉“没有 tag 就跳过还原”的分支 |
