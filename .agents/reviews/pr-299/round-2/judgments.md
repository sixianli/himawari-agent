# 第 2 轮复核：线程逐条判断

复核提交 `d81aef90`（代码在 `40ff38f4`），上一轮 `65b2d9f0`。只跑 DeepSeek（经 Magpie），一次跑成，花 0.1089 美元，累计 0.6200 美元。

## 会出错——中、高（已改，需第 3 轮再复核）

| 意见 | 判断和改法 |
|---|---|
| 主人的话以密码结尾时，密码规则把 JSON 结尾的 `"}` 吞进值，`jsonEmbedded` 解码失败，存成 `hunter2abc"}`（第 1 条） | 成立，实测复现：消息“记住我的密码是 hunter2abc”以密码结尾，表里值带 `"}`。改法：解码前先在第一个没被转义的 `"` 处截断（JSON 字符串里不可能出现没转义的引号，之后的都是 JSON 结构字符），再按 JSON 字符串解码。新增 3 条单测（普通密码、含引号反斜杠换行的密码、后面还有别的 JSON 字段），记忆整理集成测试改成按真实提示文本（含固定提示词白名单、真实哈希编号）算占位符并覆盖“消息中间、消息末尾、含引号反斜杠”三种，对话标题测试同样三种。反向验证：换回旧 `restoration.ts`，6 条新用例失败，换回新代码全通过 |
