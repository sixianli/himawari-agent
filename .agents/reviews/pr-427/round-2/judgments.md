# PR 427 第 2 轮逐条判断

- r2-1：判断「冻结工具是否带 activity」时看的是重新计算的定义，不是真正的冻结 `bundle.tools` —— 会出错（低）。只影响升级当次被恢复的运行的过程图标，不影响执行和请求字节；已改为看 bundle.tools 并补测试（反向验证过）
- r2-2：网页合并时 `activityIcon` 与 `activity` 是否为空绑定，空图标仍会覆盖旧图标 —— 会出错（低）。网页丢掉已有图标；服务器现在不会产生这种记录
- r2-3：句子清洗没有覆盖全部 Unicode 格式字符（不可见字符仍可能残留） —— 会出错（低）。文字方向错乱；其余零宽字符（如 emoji 里的 ZWJ）不该删
- r2-4：测试没有覆盖“有冻结工具、但冻结工具都不带 activity”的分支 —— 会出错（低）。没有测试报警
- r2-5：ADR 说的“工具自己的同名参数不加也不删”和 `removeToolActivity` 在边界上不一致 —— 可以更好。只在说明文字逐字相同时触发；已在 ADR 写明

r2-1 已改为看实际沿用的冻结工具（bundle.tools），新增测试在旧逻辑下失败、新逻辑下通过；r2-2 网页图标改成空值不覆盖并补测试；r2-3 加上 U+061C；r2-5 改 ADR 措辞。改动超过低严重度快速放行的规模，所以第 3 轮再用 DeepSeek 看一遍。
