# PR 323 第 1 轮判断

- ds-1（模型判中，线程判可以更好）：现象属实（治理删除某条依据记忆时，依据行随记忆级联删除，依据链少一个节点，看不出是已删来源）。这是 Andy 的删除请求造成的预期结果，不丢任何还在的数据，也不改变任何已有行为，所以判可以更好；已在 ADR 0191 写明，等 Andy 定是否要留“已删除”标记。
- ds-2、glm-2（模型判中，线程判低）：属实但开销有界（每个记忆在一次读取里最多展开一次，因为有 seen 集合）。仍已把 200 节点上限下推到持久层，超限的节点标 `truncated`。
- ds-3（模型判中，线程判低）：成立，推断路径的回滚没有反向用例；已补（依据含不存在记忆时，新推出的记忆、变更行、决策记录都不存在）。
- ds-4：成立；网关的 `complete` 现在在任一节点被截断时也为假，加了单测。
- ds-5：成立；ADR 0191 改成与迁移一致。
- ds-6：成立；决策记录的记忆编号改为由依据列表派生（不再单独传一份），写入前检查依据记忆都属于同一个 Owner 和 Agent。
- ds-7、ds-8、ds-9：成立，都是 ADR 没写明的口径；已在 ADR 0191 补上（`decisionRecordId` 是派生编号，payload 在事务之外先写，读取从被改的记忆或推断出的新记忆出发）。

- glm-3：成立；ADR 0143 两处已改为指向 ADR 0191。
- glm-4、glm-5：不成立或只是信息，不改。
