# PR 569 第 2 轮复核材料

第 1 轮成立的两条“会出错”已改：删除事务里按同样的到期条件再查一遍，不满足就跳过；新增 `retryIncompleteThreadDeletions`，每轮清理先补完线程行已删、删除记录停在“未完成”的删除。诊断回调抛错不再影响关闭。另外采纳了“可以更好”的几条：补了标题载荷被删、生效中的定时任务挡住删除、卡在 active 的对话要多等一天这三项测试；写了 ADR 0277，并在架构文档里补了重查和补删的说明。分支合进了最新 main（增量里 main 的文件不是本 PR 的改动）。
请核对这些增量，尤其是：补删只挑线程行已不存在的线程删除记录，不会碰正在进行中的主人删除；再查和补删在服务运行时与其他写入并发时不会出错。
