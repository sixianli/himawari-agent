# P4-8 线程方案：模型预评 + 一致率 + 默认关闭的自动减量

（问题、目标、约束、已核对事实同 brief-plan.md，下文只写方案。主人已定：一致率阈值 90% 按 Wilson 下限比；预评默认开、每天最多 50 条。）

## 1. 存储：新表 `decision_prereviews`（新迁移）
字段：`id`、`owner_id`、`agent_id`、`review_key`（与打分页同键，`ledger:<id>` / `mail:<id>`）、`rating`（useful/unneeded/missed/unsure）、`confidence_permille`（0–1000）、`model_ref`、`prompt_id`（提示词目录编号+版本）、`created_at`。唯一约束 (owner_id, agent_id, review_key)，每个条目只预评一次，写后不改（触发器禁止 UPDATE）。不碰 `owner_rating`。数据导出/导入一起加。

## 2. 什么时候跑
服务里加一个后台任务，跟主动检查同一个调度：每次扫打分窗口（7 天）里还没预评、文字对模型可见的条目，按打分页同样的顺序，每次最多 N 条、每天最多 `reviewPrereviewDailyLimit`（默认 50）条。已被主人评过的条目也预评（模型看不到主人的评价），这样一开就能用历史评价攒一致率。

## 3. 给模型什么、要什么
- 走 `proactiveModel(modelRef, limits)` 这条无运行的后台路径（统一出口），模型用主动检查同一个配置项。
- 系统提示（登记进 prompt-catalog，固定）：解释三种评价在各组里的含义（和打分页按钮文案同源：例如“已存的记忆：存对了 / 不该存”），要求输出 JSON `{rating, confidence}`，rating 可选 unsure。
- 唯一一条用户消息：这一条的组、kind、outcome、category、打分页显示的同一段文字。不含主人的评价、不含系统内部分数。
- 一条一请求；系统提示固定，所以前缀能命中缓存。

## 4. 周报的一致率
- `packages/calibration` 读新表，与 owner_rating 配对（邮件条目配 `proactive_processed_messages.owner_rating`）。
- 按组报：配对数、一致率 + Wilson 95% 区间、Cohen's kappa、3×3 对照表、模型 unsure 的比例。
- 配对数 < `reviewAutoReduceMinPairs`（默认 30）只写“样本不足（x / 30）”。
- 只用“主人在不知道模型预评的情况下评的”配对；减量开启后，只用抽检条目算一致率（被藏的条目主人没看，不能算）。
- 历史格式升 v4。

## 5. 自动减量（默认关）
配置：`reviewAutoReduceEnabled`(false)、`reviewAutoReduceAgreementPermille`(900)、`reviewAutoReduceMinPairs`(30)、`reviewAutoReduceConfidencePermille`(800)、`reviewAutoReduceAuditPermille`(100)。
打开后，服务在读打分页时按组算一致率（与周报同一函数）。某组 Wilson 下限 ≥ 阈值且配对数够，才在该组里藏起“模型说 useful 且把握度 ≥ 门槛”的条目；以下照常显示：模型说 unneeded/missed/unsure、把握度低、没预评、文字隐藏、按条目键哈希抽中的抽检条目（比例 auditPermille）、不在四个默认组里的（包括 P4-6 的记忆体检）。
「和历史不一致」= 模型判断和系统当初的决定相反（unneeded/missed）。
被藏的条目不占 capacity，这样主人每天看的条数不变或更少，但看到的都是更值得看的。
打分页：减量生效时显示一行“模型已预评、这次没给你看的 N 条”。条目上不显示模型预评（避免锚定）。

## 6. 测试
- 集成（真实迁移+服务入口+回环模型桩）：预评落库；主人评价前后 owner_rating 与预评互不影响；请求体里没有主人评价；文字隐藏的不预评；每日上限。
- 单测：减量默认关时 selectDailyReview 输出与现在逐字节相同；开但不达标不减；达标只藏该藏的；抽检比例；阈值读配置。
- 周报：一致率、区间、kappa、样本不足不出数。
- Playwright：减量生效那一行的正向和反向。

## 7. 放弃的做法
- 在条目上显示模型预评、让主人一键同意：省事但锚定主人，污染一致率。
- 用模型自报把握度单独决定减量：自报把握度校准差，所以必须叠加按组一致率门槛和随机抽检。
