1. 主人规则的上限过滤对“敏感主题但没有凭据、证件号”的规则不起作用：**不成立（对本 PR）。** 和第 1 轮第 2 条是同一件事。本 PR 之前规则手册不论上限列出全部主人规则，现在只少不多；写入端定级只看证件号和凭据的问题有五处写入点，设计线程已定为单独一项、出方案给 Andy（让所有写入点共用模型判断定级），不进本 PR。按模型的建议，在 ADR 0219 决定 8 的补注里写明这个已知缺口，PR 说明也写上五处位置。测试夹具直接设 sensitive 测的是本 PR 的过滤逻辑本身，不声称覆盖写入端。
2. 内置规则的参数最后展开，能盖掉编号、版本等字段：**成立，会出错，低。** 已改：参数先展开，固定字段放后面；用例让参数里带 `id`、`revision`，确认输出仍是规则自己的；改回去用例失败。

4. 版本哈希和最终输出的遮盖范围并非完全同一次：**不成立。** 只是我的说明写得不严：最终输出多出的只有版本哈希本身和“还有 N 条”的固定文字，不含会被点名的值，模型自己也没找到泄露路径。代码不改。
