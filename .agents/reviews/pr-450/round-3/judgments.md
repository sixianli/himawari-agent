# PR 450 第 3 轮逐条判断

1. 同时用“…”和分号的引文也被查了先后（模型：中）。成立，会出错，中。已改：引文里有“…”时，和只用“…”时一样不查先后；只有纯分号连接的才查先后。加了正反各一条断言。
2. 为迁就旧答案对调了实测记录的两行（模型：中）。成立，低。第 1 条改完后不需要对调，已撤回，行号重新对上。
3. “两段互换”的断言是空转的（模型：低）。成立，低。换成两段都不少于 4 个字符的正反一对断言。
4. 只查先后挡不住同序的不相干片段（模型：低）。成立，低。规则文字已如实写明这个限度；“…”本来就是这样。不再收紧：模型引用同一个文件里相隔较远的两处是常见写法，限制距离会把对的引文判错。
