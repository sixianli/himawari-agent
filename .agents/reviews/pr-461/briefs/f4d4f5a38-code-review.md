# PR 461 作者说明

问题：iOS 原生页要“导出全部数据”，网关没有对应消息；网页是一个同步的 GET，生成可能要几十秒、压缩包最大 512 MB，不能把压缩包放进网关 JSON 消息。
目标：服务器端加开始导出、查进度、取结果三件事，和网页导出共用生成逻辑；不改表，不改发给模型的内容。
做法：新增 DataExportJobs（一次一份任务，生成好的压缩包放内存，保留 10 分钟）；data.export.start 返回导出编号，data.export.status.read 返回状态和下载信息；取结果沿用 GET /api/data-export/v1/archive，加可选的 exportId 参数，不带时和以前一样现场生成；网页直下和网关开始共用同一把“同时只生成一份”的锁。做法只是参考，若你认为有更好的做法请提出。
已核对：9 个 Layer-0 相关测试文件 242 项通过；format、lint、tsc、check:operations 通过。新增 4 条导出网关用例（含正反向）和真实服务里的开始、查进度、下载用例。
