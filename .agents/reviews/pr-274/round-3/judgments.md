# 第 3 轮复核：线程逐条判断

复核提交 `fd2b3834`，增量从 `aeffe03f` 起，只跑 DeepSeek（0.0689 美元），账本累计 0.3283 美元。

## 会出错（已改）

| 严重度 | 意见 | 改法 |
|---|---|---|
| 中高 | 第 2 轮复核记录里模型原话含一个连续的 AWS 形状样例；本地加的扫描基线 CI 不认，合进 main 后历史扫描会一直命中 | 记录里把这个样例拆开写（`AKIA[拆开]…`，只改这一处，引用的原话不受影响），删掉那条基线；这个样例仍在提交 `053d2026` 的历史里，合并方式请 Andy 定（见 PR 描述） |
| 中高 | 回看窗口取消上限后，一整行很长的文字加结尾标记会很慢。实测更严重：8 万字符约 3.5 秒，5 MB 跑不完；根因是结尾标记的搜索带可选的“文件:行号:”前缀，从长行的每个位置往后扫 | 结尾标记只搜标记本身，前缀放进有限窗口里匹配；窗口恢复上限，起点挪到窗口内的下一行行首，没有就用窗口起点；补用例：4 种 200 万字符长行合计 14 毫秒，上一版 60 秒内跑不完 |
| 低 | 窗口起点所在的长行被整行当密钥遮掉 | 随上一条一起改：不再往回挪到行首 |
