# PR 490 第 2 轮复核判断

| 编号 | 结论 | 处理 |
| --- | --- | --- |
| R2-ds1 | 会出错（高） | `--init` 前若发现私有根、工作区里已有目录或已有 himawari-exec 单元就拒绝；反向验证：去掉后 qualify 报 INIT_OVER_EXISTING_ACCEPTED |
| R2-ds2 | 可以更好 | cgroup 类上限 daemon-reload 会重新应用（未在本机实测），LimitNOFILE 下次启动生效；不自动重启，避免杀掉运行中的命令 |
| R2-ds3 | 会出错（中） | 停止后核对单元是否仍在运行，仍在则报错停下；status 对已删除的也显示真实状态 |
| R2-ds4 | 会出错（低） | 改用打开目录句柄（不跟随符号链接）再改属主和权限 |
| R2-ds5 | 会出错（低） | 读账本到收敛的全过程加锁文件，已有锁则拒绝 |
| R2-ds6 | 会出错（中） | qualify 加：连续两次 apply 单元不变、不在账本里的单元不被删、remove 后再 apply 不变、账本丢失后 init 被拒 |
| R2-ds7 | 会出错（低） | 账本 uid 上限与配置一致，加测试 |
| R2-ds8 | 可以更好 | 不改 |
| R2-ds9 | 会出错（低） | 禁用 root 等保留名；收敛前检查服务账号同名组存在；加测试 |
| R2-ds10 | 可以更好 | 不改 |
| R2-ds11 | 会出错（低） | qualify 用 mkdtemp 建目录 |
