# PR 529 第 4 轮判断（deepseek-v4.1-flash）

- 1（deepseek-v4.1-flash）成立，会出错，低：### 1. 低 — ADR 0255 第 8 条没有记录代码实际会去掉的不可见字符，照文档实现会放过 U+3164/U+2800。ADR 0255 第 8 条没逐个列出被去掉的字符类别，只是文档细节；代码以共用的 hasVisibleText 为准；触发：照文档实现的人放过 U+3164/U+2800；后果：按钮文字可能看起来是空的
- 2（deepseek-v4.1-flash）成立，会出错，低：### 2. 低 — 推送边只做可见性检查，U+202E 等方向控制符仍能穿过推送边界。方向控制符（U+202E 等）能通过推送边界：它们属于格式字符 Cf，按钮文字里有可见字符时仍可显示；风险是显示顺序被反转，低风险；触发：模型写出含方向控制符的按钮文字；后果：按钮文字显示顺序异常
- 3（deepseek-v4.1-flash）成立，会出错，低：### 3. 低 — “正文不含句子”的断言仍没有真正放进一句模型句子。正文断言已按固定正文比对，没有把真实模型句子放进正文只是更强的写法；触发：有人把模型句子拼进正文；后果：句子上锁屏
- 4（deepseek-v4.1-flash）成立，会出错，低：### 4. 低 — 没有反向用例证明 quiet 提议不读 approvalCopy。提议通知不读 approvalCopy 由 quiet 分支保证，没有专门的反向用例，是测试覆盖的补充；触发：有人让提议走审批分支；后果：多读一次且可能带按钮
