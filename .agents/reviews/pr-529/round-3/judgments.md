# PR 529 第 3 轮判断（deepseek-v4.1-flash）

- 1（deepseek-v4.1-flash）成立，会出错，中高：### 1. 中 — 只去掉 `\p{Cf}`，其他不可见字符仍能让“同意”按钮显示为空。只去 Cf 不够；已改成共用函数 hasVisibleText：去掉 Cf、Mn、Me、默认可忽略码点、盲文空白和空白后，要求还剩字、数字、标点或符号；两端共用；触发：模型把按钮文字写成只有变体选择符、盲文空白或韩文填充符；后果：锁屏“同意”按钮显示空白
- 2（deepseek-v4.1-flash）成立，会出错，低：### 2. 低 — ADR 说按钮文字“只有几个字”，但 `affirmLabelMax` 允许配置到 64 个字形。已把 ADR 措辞改成默认值加上限 64；触发：有人把 affirmLabelMax 配到 64；后果：ADR 里“只有几个字”的说法比实际保证强
- 3（deepseek-v4.1-flash）成立，会出错，低：### 3. 低 — ADR 0255 第 8 条没有记录代码新增的“无可见字符”拒绝条件。已在第 8 条补上无可见字符一项；触发：后来的人照 ADR 第 8 条的拒绝清单核对代码；后果：清单少一项
- 4（deepseek-v4.1-flash）成立，会出错，低：### 4. 低 — “正文不含句子”的新断言是空断言，不能拦住句子进锁屏。已改成断言正文等于固定的对话标题；触发：以后推送把某句话放进正文；后果：旧断言不会失败
