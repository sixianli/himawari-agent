# PR 460 第 1 轮代码复核：逐条判断

只用 DeepSeek（Andy 2026-11-12 起的默认）。没有“会出错”的意见，4 条都是“可以更好”。

| 编号 | 意见 | 处理 |
| --- | --- | --- |
| ds-1 | `/lib64` 在所有平台上都变成“可选”，x64 上缺失时测试不再报错 | 不改：x64 的发行版都带 /lib64，缺失只会出现在 ARM；可选清单由调用方传入的能力已有（`optional` 参数），固定默认值是有意的最小做法。列给 Andy。 |
| ds-2 | ADR 说“取真实路径之后按原顺序去重”，但 `mac-sandbox-deployment` 关掉了去重 | 已改：ADR 补上默认去重、该调用点显式关闭的说明 |
| ds-3 | 默认 `/lib64` 的单元测试依赖宿主机状态，异常宿主上会误判 | 已改：用 realpath 的结果算期望并断言具体值，不再只比长度 |
| ds-4 | 没有自动检查确保四处调用方真的使用了新函数 | 已改：单元测试里加了读四个调用方源码、断言导入并调用新函数的用例 |
