# 网页设计基线

设计或修改 Himawari 网页之前读本文件。

- 每个设计或修改网页的会话，包括协调者和云端线程，都要先读 [docs/ui-ux-design-guide.md](../../docs/ui-ux-design-guide.md)：它的规则、用户批准并喜欢的设计，以及已经遇到过的不良设计。交付时，把每个新的 UI 或 UX 问题加入其中的不良设计，把用户批准的每个设计加入其中的良好设计，把它们教会的任何规则加入其中的规则；能自动检查的规则还要配一项检查，例如在 `scripts/check-layout-audit.mjs`（`npm run check:layout`）中加一个场景或检测器。
- 修改 Himawari 网页的视觉设计、聊天交互或品牌素材之前，先读[当前 v4 交互与视觉基线](../../docs/execution/specs/2026-09-15-control-center-v4-design.md)和[原始 logo 基线](../../docs/execution/specs/2026-09-10-control-center-visual-baseline-design.md)，并打开其中引用的可交互原型和视觉效果图。
- `assets/brand/himawari/v1/` 和 `docs/assets/control-center/2026-09-10-v1/` 保存着用户批准的原始设计。后续实现的布局、主题、每轮执行过程和工具展示，都要对照这些参考检查；不得覆盖基线文件。用户批准某项设计改动后，把它另存为新版本，并更新文档中的引用。
- 当前聊天页必须遵循 `docs/assets/control-center/2026-09-15-v4/` 中冻结的原型，加上位于 `docs/assets/control-center/2026-09-27-v5/` 的执行环境状态行和侧边栏运行标记，加上位于 `docs/assets/control-center/2026-10-26-v6/` 的时间条过程区和向日葵花盘标志（该原型的其余部分尚未批准，新标志的品牌素材在 `assets/brand/himawari/v2/`），加上位于 `docs/assets/control-center/2026-10-27-v7/` 的手机聊天页（回答下方不显示模型名，一行记忆提示，安全区内边距，圆形发送按钮），加上位于 `docs/assets/control-center/2026-10-28-v8/` 的对话“更多”面板（标题栏上一个按钮，只显示正在运行的后台命令数；“文件”标签页和“后台”标签页，按轮次分组；桌面上是右侧栏，手机上是底部弹出面板），加上位于 `docs/assets/control-center/2026-10-28-v9/` 的一批界面改动（一句话的过程摘要并附总用时，步骤下方只显示 token 总数和 KV 缓存命中率，操作按钮只放在回答下方，记忆页和提醒页分开，设置对话框分四个标签页），加上位于 `docs/assets/control-center/2026-10-29-v10/` 的 Gmail 提醒、提醒检查记录、没提醒的邮件和已连接应用设置（颜色只用来表达含义，红色表示需要 Andy 处理的事，琥珀色表示值得看一眼或已自行恢复的情况，紫色只用于可以点击的东西），加上位于 `docs/assets/control-center/2026-10-29-v11/` 的一批界面改动（顶栏由两组分开的悬浮圆形按钮组成，标题居中，设置放在侧边栏底部；分支出来的对话显示它的来源轮次和出处；命令步骤把命令本身收进“命令详情”；使用页面自己的下拉菜单；在文件页上传），加上位于 `docs/assets/control-center/2026-10-29-v12/` 的记忆页（两个标签页，“记忆”和“变更”；顶部一张卡片，显示每次对话都会带上哪些记忆，每条记忆有一个由 Andy 控制的开关；按主题浏览，桌面上用侧边列表，手机上用下拉菜单；详情放在抽屉或底部弹出面板里；不加“新”标签），加上位于 `docs/assets/control-center/2026-10-30-v13/` 的向日葵标志（2026-11-25 起种子数按显示大小取：28px 及以下 21 颗、29 到 46px 34 颗、47 到 56px 55 颗、57 到 72px 89 颗、更大 144 颗，见 [ADR 0291](../../docs/adr/0291-sunflower-mark-seed-count-follows-its-size.md)；按黄金角排布，只有圆点、没有花瓣；新种子从中心长出，把旧种子向外推，但只有首页标志和正在生成的回答的标志会动，其他一律静止，开启“减少动态效果”时什么都不动；`assets/brand/himawari/v2/` 中 96 颗种子的花盘和 `v3/` 中 233 颗的花盘现在是历史参考，新的在 `v4/`），加上位于 `docs/assets/control-center/2026-10-31-v15/` 的圆润造型（双色填充图标，只从 `glyphs.tsx` 取，新图标照同样画法；组件不描边，侧栏、卡片、菜单、弹窗浮起带阴影；按钮胶囊形，只有主按钮实心；iOS 式开关；一行高的胶囊输入框；顶栏圆形按钮；手机侧栏是浮动卡片、点外面关闭，弹窗从底部弹出；颜色不变；v14 的柔线造型已作废）；加上位于 `docs/assets/control-center/2026-11-03-v17/` 的提醒页“校准周报”标签（提醒页分“提醒 / 校准周报”两个标签；观察期卡片 7 个格子，点开看每天的检查明细；按决策类型每一行用自己的说法写比例，评过的少于 5 条写“样本不足”；解释文字收进标题旁的 ⓘ，电脑弹小框、手机从底部弹出；日期只在标签下方显示一次；设置里的四个提醒统计搬到这里）；加上位于 `docs/assets/control-center/2026-11-05-v18/` 的设置“数据”栏里的“敏感信息拦截记录”（数据栏一行写条数，点进去按天列出类别、出处和次数，顶部按结果筛选，底部写“记录不会自动删除；删掉对话时一起删除”并可清除；能点的“打开对话”用主题色，不用原型里演示的紫色）；保留 v1 作为历史参考和品牌素材的来源。改动不得重新引入独立的审批入口或删除对话的操作，也不得新增堆积内部运行信息（模型、token、步骤、审批、内部记录）的通用面板或页面。有特定用途的面板或页面，在用户批准其原型并将其另存为新的基线版本后，可以添加。
- 原型中的消息、模型、思考摘要、工具输出、用时和审批都是演示数据。它们不能证明生产功能已经实现，也不能证明真实执行已经成功。
