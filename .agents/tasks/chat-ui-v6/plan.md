## 决定

- 时间线先在前端用纯函数算，记录里的时刻都是服务端发生时刻；原设计写的“在服务端算”推迟，等有第二个客户端时再把同一个函数挪到共用包。原因：现在只有网页一个客户端，服务端算要改接口合同和快照，工作量大一倍，准确性没有区别。
- “等你确认从卡片出现算起”这一期不做：接口里没有记录存入时刻。记录晚到 3.6 秒本身是要另查的问题，修好它比改归类更对。
