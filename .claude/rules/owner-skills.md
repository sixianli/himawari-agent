# Owner's Skills in This Repository

The owner's Claude Code skills are copied into [.claude/skills/](../skills/README.md). A skill is a folder of working instructions with `SKILL.md` as its entry point. Cloud threads in a claude.ai project do not load skills from a repository's `.claude/skills/`; they only load `CLAUDE.md`, `.claude/CLAUDE.md`, and `.claude/rules/` at the repository root. This file is how such sessions reach the skills.

- When the Skill tool already lists a skill with one of the names below, use that skill and ignore the copy here.
- Otherwise, when a task matches a description below, read `.claude/skills/<name>/SKILL.md` with the Read tool before acting and follow it as if the skill had been loaded. Paths inside a `SKILL.md` are relative to its own folder; for example, `scripts/longtask.py` in `long-task-planning` is `.claude/skills/long-task-planning/scripts/longtask.py`.
- An instruction that names `~/.claude/skills/<name>/...` means the same file under `.claude/skills/<name>/...` when the first path does not exist.
- The copies are snapshots. Do not edit them in a task; [the README](../skills/README.md) explains how they are refreshed.
