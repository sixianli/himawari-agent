# Himawari 标志备选：生长与ひ

**Context/Project:** Himawari Agent

## Core Ideas

Andy 在 2026-10-30 看了标志（logo，产品的图形标识）自由设计的 5 个方案后，选出第 2 版“生长”和第 3 版“ひ”留作备选，暂不替换线上标志。可交互原型（浏览器打开即可看动效）存在 [docs/assets/brand-candidates/2026-10-30-logo/index.html](../assets/brand-candidates/2026-10-30-logo/index.html)，静态截图是同目录的 preview-idle.png。“生长”：只用圆点，按真实向日葵的长法，种子从花心按黄金角（137.5°）一颗颗长出，把老种子推向外圈，寓意每次对话添一颗种子、记忆越积越满，对应愿景里的“时间站在 Himawari 这边”；动效只是这个生长过程，空闲时慢、思考中快、等待时中心新种子发光。“ひ”：取“ひまわり”第一个假名“ひ”，形如一只碗，碗里托着一颗金色小太阳（“ひ”也是“日”的读音），一笔线加一个圆；首次出现时一笔写出“ひ”、太阳升起，思考中太阳在碗底来回滑动，等待时太阳呼吸发光。两版都在系统开启“减少动态效果”时静止。

## Thought Trajectory

同一线程里先后做了四轮：第一轮 5 个点阵方案，Andy 喜欢“呼吸”动效但要更像向日葵；第二轮加了实心花瓣，Andy 要求整个标志只用圆点、靠点的大小和颜色做动效；第三轮做了纯圆点花瓣，Andy 选“一条螺旋长出整朵花”，并试了 1005 点精细版、105 点版和 1005/377/233 点大小图搭配，仍不满意；第四轮放开限制，从名字“向日葵＝朝向太阳”和愿景“始终朝向你”出发，做了朝向、生长、ひ、花冠、日轮 5 版，Andy 认可生长和ひ。各轮原型在项目共享文件夹 logo-redesign/ 下。

## Open Questions

1. 最终选生长、ひ，还是两者组合（例如“ひ”作 App 图标和文字标志，“生长”作首页大图和思考中动效）？2. “生长”在 20px 以下偏暗，落地时是否给小尺寸单独配色或减点？3. “ひ”不直接像向日葵，作为品牌标志是否接受？4. 落地前要按“先讨论再开工”出方案，并按 UI 规范把定稿存为 assets/brand/himawari/ 的新版本。
