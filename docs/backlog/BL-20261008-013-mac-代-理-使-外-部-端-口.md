# Mac代理使外部端口检查产生成功假象

## 期望结果

使外部端口检查从能直接观察目标网络的外部主机执行，并同时检查对照端口，避免把 Mac 本机代理的连接成功误写为生产端口开放。

## 来源与证据

来源为 Claude 在生产服务器上读回后编写的[生产沙箱修复简报](../../.ci-output/handoff/2026-10-08-codex-prod-sandbox-brief.md)“记录但本批不修”部分。Codex 本次只在 Mac 上登记文档，没有连接生产服务器、读取生产秘密或重跑生产命令。

Claude 报告从 Mac 发起检查时，本机代理对任何端口都返回连接成功，因此该检查无法证明目标端口可达。简报要求使用 Hermes 等外部主机并带对照端口。本次没有发起网络检查，也没有确认当前代理配置。

## 后续范围与约束

后续证据应说明检查来源、目标和对照端口，以及代理是否介入；对照失败时不得报告目标端口已确认开放。Hermes 作为检查来源也必须有实际连接结果，不能用 Mac 历史成功替代。
