# P7秘密初始化中断后不能安全续做

## 期望结果

使 P7 能识别已完成的随机密钥写入与尚未完成的 API key 写入，在中途中断后按当前受保护状态安全续做。续做不得覆盖已写密钥或重复产生无法追溯的秘密。

## 来源与证据

来源为 Claude 在生产服务器上读回后编写的[生产沙箱修复简报](../../.ci-output/handoff/2026-10-08-codex-prod-sandbox-brief.md)“记录但本批不修”部分。Codex 本次只在 Mac 上登记文档，没有连接生产服务器、读取生产秘密或重跑生产命令。

Claude 报告生产 P7 在随机密钥已写、API key 尚未写时中断，原脚本无法续做；Claude 最后使用只补 key 的脚本完成。本次没有读取或改写任何密钥与 API key。

## 后续范围与约束

后续应覆盖关键写入点中断后的重入、现有密钥保留、状态不一致拒绝和完成状态的独立读回。生产临时补 key 不证明正式 P7 已具备可重复恢复能力。
