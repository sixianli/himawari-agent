# 模型行为改动的评测脚本：改提示词或工具定义后用真实模型实测指标

## Summary

按 ADR 0063 的“改提示词、工具定义、模型映射要实测”：加一个手动运行、不进 CI 的评测脚本，对 AI Gateway 上的 deepseek/deepseek-v4.1-flash 跑一组写好期望结果的合成场景（例如工具选择、审批判断），输出准确率等指标；支持改动前后两版提示词对比。假模型的测试只证明配置传对了。
