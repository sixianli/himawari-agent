# 冻结诊断脚本夹具缺少 text 字段，prod-sandbox-diagnostic 测试在基线上就失败

## Summary

test/tooling/prod-sandbox-diagnostic.test.mjs 的用例“validates with the product schema and exports only fixed enums and known field names”在 276a4b67 不带任何补丁时就失败（Hermes，R2-H1 批次的对照运行 diag-tooling-01、l2-base-01，证据 /data/hermes/himawari/tool-audit-round2/r2-h1/evidence/）。原因：提交 5bab4de1 给 packages/execution-contracts/src/sandbox-execution-v2.ts 的 sandboxHostFailureDetailSchema 加了必填字段 text，而夹具 test/fixtures/prod-sandbox-readonly-diagnostic.mjs 的 detailFields 没有 text，selectFields 把它删掉后 schema.parse 失败，抛 DIAGNOSTIC_SCHEMA_INVALID。这个夹具对应冻结操作包里的只读诊断脚本（D1），意味着真实诊断输出含 text 时该脚本也会拒绝。修法：detailFields 加 text、测试数据加 text（含 null 的情况），同步核对操作包里的诊断脚本副本；先红后绿，第 0 层在 Hermes 跑。2026-10-21 发现于 R2-H1 第 2 层。
