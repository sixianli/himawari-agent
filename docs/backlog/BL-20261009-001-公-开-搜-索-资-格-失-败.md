# 公开搜索资格失败后保留可诊断现场

## 期望结果

公开搜索资格失败时，保留能区分连接拒绝、服务返回错误和子进程失败的证据。原检查、网络授权、期限、输出限制和清理要求保持不变。保留经过过滤的错误类型、固定错误码、连接计数、认证 final 和命名空间状态，不输出原始堆栈、代理 URL 或 token。

## 来源与已确认事实

[reply-04](../../.ci-output/handoff/2026-10-08-codex-prod-sandbox-reply-04.md)要求非阻塞问题进入 Backlog，同时保留本次第二部署的全部资格检查。[ADR 0051](../adr/0051-second-production-host-acceptance-exception.md#first-install-acceptance)规定 Hermes 适配证据不能替代生产主机资格。

Hermes `acceptance-rehearsal-03` 的首个 public-query 在 2.833 秒后报 `WEB_SEARCH_FAILED`，另外两个搜索场景和第七项 R2-L6 没有执行。[原报告](../../.ci-output/handoff/prod-second-evidence-05/reports/acceptance-rehearsal-03/rehearsal/run-01/web-search-installed.json)保留退出结果；命名空间释放及 `network.closed=true` 的断言已通过。原 adapter 的 `finally` 随后删除场景，报告未保留 `connected`、`deniedTargets` 或 `deniedAddresses`，无法再独立恢复这些计数。

runner 摘要与第 02 次通过结果相同，runtime 前后摘要也相同。具体搜索失败原因仍为 `uncertain`；现有证据不能归因于 Exa、新安装目录或期限。

## 验收边界

未来修复需要用可重复的失败场景证明：失败证据在消费者结束后仍能独立读回，保留内容不包含秘密；正常释放仍检查原断言。原始失败报告及现场的唯一副本不能因保留步骤失败而删除。

本条只记录失败取证缺口，不批准跳过公开搜索、R2-L6 或任何签署前检查。独立诊断和单次搜索成功都不能代替完整七项资格。本次候选继续使用已批准的原 runtime 和原资格入口，独立诊断另列证据。
