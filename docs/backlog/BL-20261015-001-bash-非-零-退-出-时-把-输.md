# bash 非零退出时把输出连同未核实提醒交给模型

## Summary

用户 G109（2026-10-15）同意：bash 命令以非零退出码结束时，模型现在只看到“命令执行失败…请先检查工作区”，看不到标准输出和标准错误，测试失败等情况无法排错。改为把有界的输出连同“效果未核实”的提醒一起交给模型。现行设计见 [SRT 统一执行设计](../execution/specs/2026-09-07-srt-unified-execution-design.md)（第 423 行附近），需先修订该规格。按 G109 第 1 项，不进第四次生产变更，排在第五次。
