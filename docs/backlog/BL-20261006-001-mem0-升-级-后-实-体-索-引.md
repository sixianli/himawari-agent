# Mem0升级后实体索引混入产品记忆库

## Summary

用户G46要求升级Mem0最新版。Hermes实际mem0ai3.3.1经产品投影入口更新包含人名公司地点的记忆后，vectors.sqlite出现5条而非2条产品记录，其中3条实体无product_memory_id。新版实体库路径仅替换.db后缀，产品既有.sqlite路径与主库相同。需保持既有主库和历史库路径，复用SDK向量存储为实体明确分配独立路径，并保留更新、查询、重启与删除的自动检查。证据E20261006T191027-0b16e1，原SDK请求与SQLite读回在r64/l5-migration-01/mem0-entity-red-01。
