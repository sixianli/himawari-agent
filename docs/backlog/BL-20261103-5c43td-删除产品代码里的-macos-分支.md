# 删除产品代码里的 macOS 分支

## 期望结果

产品代码和测试里不再有 macOS 专属的实现和分支；判断运行平台的地方只接受 Linux，在其他系统上启动时明确报错并退出，而不是走进一条不再维护的分支。

## 来源与背景

- Andy 2026-11-03 决定 Himawari 只在 Linux 上运行，见 [ADR 0156](../adr/0156-linux-only-runtime.md)。该 ADR 决定 5 把现有 macOS 代码冻结：不再维护、不补测试、新代码不得新增 macOS 分支，删除另行处理。
- 已知的 macOS 实现（2026-11-03 用 `grep` 查到，不是完整清单）：
  - Mac Seatbelt/XPC 命令沙箱：`packages/platform-node/src/workspaces/mac-seatbelt-xpc-command-sandbox.ts`；
  - Apple container 命令执行：`packages/platform-node/src/workspaces/apple-container-command-provider.ts`；
  - 钥匙串（macOS 保存密码和密钥的系统服务）密钥来源：`packages/platform-node/src/host-secret-source.ts`、`apps/admin-cli/src/account-command.ts`；
  - `packages/runtime-sandbox`、`packages/execution-contracts`、`packages/platform-node`、`apps/agent-service`、`apps/execution-worker` 中按 `darwin` 判断的分支及对应测试。

## 边界

- 删除动到沙箱、安装和密钥读取，按 [Andy 定的长期规则](../../.claude/rules/owner-standing-rules.md)属于大改动：先出方案（附业界做法和一手来源），按[和 OpenCode 协作](../../AGENTS.md#working-with-opencode)请两个模型各自出方案、再审线程的方案，Andy 同意后再动工。
- 删除时同一提交更新受影响的 Runbook 和架构文档；按快速模式跑基本检查（定向测试、`npm run check`、`npm run build`），只在 Hermes 或云服务器 `himawari-ci` 账号上跑，不在 MacBook 上跑。
- 历史证据和已取代的 ADR 不改。
