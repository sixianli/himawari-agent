# doctor把已配置内置身份恒报为不可用

## 期望结果

使 doctor 根据内置身份的实际可用状态报告 identity，避免仅因配置了内置身份就得到 ready=false。保留身份缺失、配置不一致和公共模式的既有安全要求。

## 来源与证据

来源为 Claude 在生产服务器上读回后编写的[生产沙箱修复简报](../../.ci-output/handoff/2026-10-08-codex-prod-sandbox-brief.md)“记录但本批不修”部分。Codex 本次只在 Mac 上登记文档，没有连接生产服务器、读取生产秘密或重跑生产命令。

静态代码已确认：apps/admin-cli/src/index.ts 的 doctor 将 configuration.identity 或 configuration.publicMode 为真时的 identity 恒置为 unavailable，ready 又要求该依赖为 available。Claude 报告首次部署时配置内置身份仍得到 ready=false；本次没有执行 doctor。

## 后续范围与约束

后续修复必须用可重复测试覆盖已配置且可用的内置身份、缺失或不可用的身份，以及 publicMode 的对应合同。本批只记录，不把静态条件当作生产就绪判断。
