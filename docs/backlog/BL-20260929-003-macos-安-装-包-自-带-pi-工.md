# macOS 安装包自带 Pi 工具使用的 Bash

## 期望结果

macOS 安装包自带一份 Bash，安装后位于 `runtimeRoot/pi-tools/bin/bash`，计入 runtimeDigest（整个安装内容的摘要），用户安装后不需要额外步骤，模型的 `bash` 工具就能使用。分发时附带 Bash 的 GPLv3 许可证原文，并提供对应源码或获取源码的明确方式。

## 来源与背景

- 用户 2026-09-29 在三种做法中选择“安装包自带 Bash”，决定及比较见 [ADR 0037](../adr/0037-macos-bundled-bash.md)。
- 现行规定是由安装者自己准备 Bash，见[安装启停 Runbook](../runbooks/install-start-stop-runbook.md)。macOS 系统 Bash 带苹果平台签名，复制后运行会被系统终止；工具执行排查中测试改用 ad-hoc 签名（只在本机有效、不经苹果认证的签名）的系统 Bash 副本，证据见[第二轮 reply-1](../../.ci-output/handoff/2026-09-28-round2-claude-reply-1.md)。

## 开始前要由用户确认的事

- Bash 的来源：使用已有的编译产物，还是从 GNU 官方源码自行编译；以及版本。获取时需要下载，下载前先问用户。
- 签名方式：只做 ad-hoc 签名，还是用开发者证书签名并经苹果公证（把程序交给苹果做自动安全检查，通过后其他 Mac 才会直接放行从网上下载的程序）。这会影响安装包能否在其他用户的 Mac 上直接运行。
- 安全更新的跟进方式。

## 边界

- 只涉及 macOS；Linux 仍按现行 Runbook 由安装者准备。
- 实现落地前不修改 Runbook 的现行规定；实现时在同一次修改中更新并重新封存安装启停 Runbook。
- 实现前先写 Spec 和 Plan，本条再转为 `converted` 并链接到它们。
