# 模型网关迁移到 Vercel AI Gateway

## Summary

按 ADR 0048 把生成模型和 Memory 嵌入模型从 OpenRouter 迁到 Vercel AI Gateway：改描述符和配置、删掉 OpenRouter 专有字段、核对用量和费用回读、更新测试、Runbook 和架构文档；默认模型、备用模型、嵌入模型和排期待用户决定。

## Origin

- 2026-10-04 用户原话：“之后这个项目不在使用openrouter ,而是使用vercel作为 ai gateway”。决定见 [SOURCE: docs/adr/0048-vercel-ai-gateway-replaces-openrouter.md]。

## Notes

- 已验证：Pi 0.84.2 的 `openai-completions` 接口指向 `https://ai-gateway.vercel.sh/v1`，用 `openai/gpt-6-astra` 流式输出成功（细节见 ADR 0048 的“已验证的事实”）。开发密钥在 Mac 钥匙串，服务名 `himawari.ai-gateway.dev`。
- 要改的地方（2026-10-04 用 `git grep -il openrouter` 找到）：
  - `packages/runtime-pi/src/configured-model-binding.ts`：描述符里写死的 `provider: "openrouter"`、OpenRouter 地址和 `providerRouting` 字段；
  - `packages/runtime-pi/src/pi-model-transport.ts`：`openrouter_metadata` 的旁路读取和 `OPENROUTER_*` 错误码；
  - `apps/agent-service/src/production-model-composition.ts`、`production-memory-composition.ts` 和 `packages/memory-mem0/src/index.ts`：生成模型和嵌入模型的组合；
  - 相关单元测试、集成测试、`test/fixtures/product-path-harness.ts`、`ci/policy.json`、`scripts/operations/` 下的比较脚本；
  - 架构文档、`install-start-stop` 和 `hermes-control-center-upgrade` 两份 Runbook，以及 README。
- 用户 2026-10-04 已决定（见 ADR 0048 补充决定）：排在上线前；禁止使用 OpenAI 模型，文本模型只用 `deepseek/deepseek-v4.1-flash`，去掉现有的 GLM 备用。嵌入模型沿用 Qwen3 Embedding 8B（网关编号 `alibaba/qwen3-embedding-8b`）。长任务里对应条目 R2-L5。
- `deepseek/deepseek-v4.1-flash` 单次最多输出 32768 token，比现在的 DeepSeek V4 Flash（384000）小，迁移时要核对产品的 `maxTokens` 和输出截断处理。
- 生产密钥的创建和写入生产服务器，需要用户为那次部署单独授权。
