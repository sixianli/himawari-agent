# 运行时长上限与工具期限同时到达时命令原因可能记成取消

## Summary

D-55 诊断（.ci-output/handoff/2026-10-22-l4-9969-diag-oc-stop.md 第 1.3、4.1 节）指出：Worker 的运行时长上限（apps/execution-worker/src/production-execution-worker.ts 约第 642-663 行）若与工具期限落在同一时刻，取消请求会以 cancelled 抢先决定常驻命令的结束原因，结果记成未知而不是期限超时。本次第 4 层失败的证据没有指向这条路径，D-55 只改了 Job Host 的会话停止顺序；Worker 在 resolve 失败后取消命令时的原因归因没有改（试过，原因未证实，已撤回）。要先确认运行时长上限与工具期限在生产配置里能否相同，再决定是否让到期后的上限取消按期限归因。
