# Hermes 完整测试时偶发的单个用例超时

## Summary

2026-10-15 在最终候选 04660f2b 上，Hermes 第 3 层（完整 npm test，5772 个用例）两次各有一个不同的用例超时：第一次是 node-runtime-installation-permissions.test.ts 的“安装完整产物”用例跑满 30 秒（此前 5 次为 21.5–24 秒，当时 Claude 在同一块盘上删除旧副本，判为受干扰）；第二次是 sandbox-control-evidence.test.ts 的“同一次开机内作业宿主崩溃：宿主和进程组都已消失”用例，本体约 4.7 秒（平时约 1 秒）后清理钩子等满 10 秒，这段时间没有找到外来进程。第三次运行全部通过，期间 /proc/pressure/io 的 avg10 最高约 42%，根盘已用 96–97%。推测是磁盘写入停顿让 fsync 和数据库关闭变慢，尚未证实。按 AGENTS.md，Hermes 上的超时要当缺陷诊断，不能放宽时限。下一步：在负载日志里已有 IO 压力的基础上，把失败用例所在文件在完整测试的并发下重复运行，并同时记录 IO 压力，确认是否与停顿同时发生；如果是，再看安装类用例能否减少写入量，或者让 R2-T8 的测试提速覆盖这两个用例。
