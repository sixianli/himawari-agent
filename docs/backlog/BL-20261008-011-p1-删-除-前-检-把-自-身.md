# P1删除前检把自身命令行误判为残留引用

## 期望结果

使 P1 删除前检区分检查命令自身出现的目标路径与其他进程真实引用，避免外层 ssh/bash 命令行字符串导致错误拒绝。

## 来源与证据

来源为 Claude 在生产服务器上读回后编写的[生产沙箱修复简报](../../.ci-output/handoff/2026-10-08-codex-prod-sandbox-brief.md)“记录但本批不修”部分。Codex 本次只在 Mac 上登记文档，没有连接生产服务器、读取生产秘密或重跑生产命令。

Claude 报告生产 P1 前检把外层 ssh/bash 命令行中出现的待删除路径算作残留引用而失败。本次未执行删除前检，没有观察生产进程或删除任何路径。

## 后续范围与约束

后续应在隔离的测试目录验证检查者自身参数、真正持有目标 cwd 或 fd 的进程，以及无法判定的引用。保留未知引用拒绝删除的要求，不能按进程名放行或删除原失败证据。
