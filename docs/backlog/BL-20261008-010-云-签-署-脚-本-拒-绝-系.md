# 云签署脚本拒绝系统工具的合法符号链接路径

## 期望结果

使云签署检查能在核对最终规范路径、文件身份及摘要的同时处理已批准的系统工具符号链接，避免 Ubuntu 24.04 上的合法 socat 路径阻止签署。

## 来源与证据

来源为 Claude 在生产服务器上读回后编写的[生产沙箱修复简报](../../.ci-output/handoff/2026-10-08-codex-prod-sandbox-brief.md)“记录但本批不修”部分。Codex 本次只在 Mac 上登记文档，没有连接生产服务器、读取生产秘密或重跑生产命令。

静态代码已确认 signing/cloud-seal.mjs 对 bwrap、socat、bash、rg 都先求 realpath，再断言结果与输入路径相等。Claude 报告生产 /usr/bin/socat 指向 socat1，原断言失败；Claude 使用去掉该断言的副本签署，回执记录 /usr/bin/socat1。本次没有读取生产回执或核对生产链接。

## 后续范围与约束

后续需明确允许的工具解析合同，保留摘要和身份检查，并覆盖合法链接、意外目标和链接变化的拒绝情形。不能直接把生产使用的删断言副本当作正式修复或已验证签署来源。
