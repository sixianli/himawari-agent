## 当前证据与范围

起点为 `585ac00`，`codex/web-page-refactor` 工作区干净，SRT 分支仍为祖先。原重构的分项测试通过，但完整入口在 integration 执行 300019 毫秒时被 SIGKILL，随后读取缺失 JSON 报告掩盖原始超时。现行 CI policy 规定 test 检查总时限为 30 分钟，没有每项目 5 分钟的业务要求。

本轮让五个项目共享该既有总预算；父检查准备时间计入预算，耗尽即停止，不增加 policy 时限、不重试或删减测试。进程超时或启动失败直接记录所属项目和终止原因，不尝试把缺失报告当成普通测试结果。

第一次完整执行已越过原 300 秒中断点，并完成全部 1,914 项；其中 6 项 SQLite/UDS 集成用例触发 Vitest 默认 5 秒超时，其余 1,908 项通过。涉及的两个文件单独复现时 42 项全部通过，用时约 14 秒；完整运行同期磁盘采样也出现 30 秒超时，表明存在 I/O 延迟，但没有证明采样是唯一原因。为真实数据库、线程和本地通信测试明确设置 integration 项目默认 `testTimeout: 30_000`，保留测试内显式业务期限、其他项目默认时限和整个检查的既有 30 分钟预算。修正后重新执行完整五项目检查；重跑不是自动 retry，首次失败证据保留。

## 正式本机服务

沿用正式 Agent Service、Execution Worker、SQLite、受保护 Payload、Pi 0.84.2 和 OpenRouter 链路。独立运行目录为 `~/.himawari-local`，与旧受控预览服务区分。用户已明确允许复用现有 OpenRouter 钥匙串凭据、创建该目录及专用加密钥匙串项；本次总模型费用不超过 1 美元，工具只操作其中专门创建的验收文件。原始模型凭据不复制到仓库、不输出到日志。

先核对运行所需的配置、身份和能力安装合同。真实工具必须取得本机资格并走现有授权与 Worker 边界；缺少资格时保持拒绝，不能移植测试中的伪造合格记录。若正式首次初始化存在缺口，先明确缺口与必要初始化范围，再按现有领域合同补齐。

## 本机身份扩展提案（待确认）

实际检查发现，`createProductionHttpComposition()` 固定构造 Cloudflare JWT 验证器及身份查询客户端；`ProductSessionAuthenticationService.authenticate()` 每次请求都要求外部 assertion。现有 loopback bootstrap 只是绑定外部 subject，不提供本机登录。`publicMode: false` 也不是本机 Web 模式：正式 HTTP 组合会拒绝启动。当前管理 CLI 没有首次初始化命令。故仅创建配置、复用 OpenRouter 凭据，不能得到可日常使用的正式网页。

建议增加显式的本机 Owner 身份适配器，与现有 Cloudflare adapter 并列。只监听数字 loopback，校验固定 Host/Origin，拒绝远端转发和跨站请求；由本机管理入口产生短时、一次性登录凭据，通过受保护文件或交互输入交付，不进入 URL、命令参数、日志或浏览器长期存储。凭据兑换为现有可撤销的设备与产品会话；敏感审批需要真实的再次本机认证，使用明确的本机认证来源，不能冒充 Cloudflare 登录或 MFA。继续使用现有 CSRF、Owner 归属、单次行动授权、审计和 Payload 边界。

首次初始化只创建用户已授权的新 state root、唯一 Owner/Agent/deployment、专用钥匙串引用和显式模型配置，不覆盖已有目录。运行入口应可执行启动、状态检查和停止，并能让用户完成再次登录。HTTP loopback 的本机模式需要独立的配置校验，不能放宽公共部署的 HTTPS/外部身份要求。

影响涉及配置合同与解析、身份适配及近期认证来源、HTTP 组合、CLI 初始化、登录页面、文档和相应安全回归测试；不改聊天视觉、模型协议或工具授权策略。这是重要身份语义扩展，按用户原要求等待确认后实施。替代方案是配置真实 Cloudflare Access/Tunnel，但需要外部账户和网络入口配置，不属于已经批准的纯本机运行范围。

工具安装资格另行以当前安装产物和主机实测建立。现有 SRT 探针及保存的安装证据明确标记 `productionSuitable: false`；主机验证器只检查部署快照，不签发资格。不得直接复制这些测试记录或手写合格布尔值来获得工具准入。若实际探针暴露超出本次范围的监督器缺口，另报具体证据和方案；本机身份确认不等于批准降低工具隔离要求。

## 验收

完整项目测试一次运行通过并保存报告。真实浏览器连接正式本机服务，验证多轮聊天、模型与深度、真实文件工具、批准/拒绝、停止、断线和服务重启后的历史、草稿与恢复。记录每项证据属于真实服务还是受控故障注入；不编造 thinking、工具结果或审批。

不推送、创建 PR、部署到 Hermes 或扩大目录授权。最终记录本地提交、运行入口、实际费用和未完成项。
