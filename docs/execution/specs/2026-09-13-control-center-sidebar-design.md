# 控制中心侧栏与导航修订

## 目标与来源

用户于 2026-09-13 指出现有侧栏把按钮、筛选、对话和未启用功能堆在一起，要求参考其提供的 Codex 与 ChatGPT 网页版截图改善界面与交互。此次调整导航层级、列表滚动和标题栏，保留既有向日葵品牌、明暗主题、聊天与工具记录。

- 原始视觉与交互基准：[SOURCE: docs/execution/specs/2026-09-10-control-center-visual-baseline-design.md]
- 控制中心功能和无障碍要求：[SOURCE: docs/execution/specs/2026-08-26-control-center-experience-design.md]

原始 v1 原型与效果图保持原样。本说明记录后续修订，不代表 Codex 或 ChatGPT 的内部实现，也不引入演示项目、虚构账号或未实现的能力。

## 设计

- 桌面侧栏宽 272 像素，中等窗口收窄至 240 像素；支持收起和重新展开。手机继续使用已有抽屉入口。
- 品牌下方依次提供新建、搜索和审批。搜索表单按需展开，保留原有标题及授权内容搜索。
- 活跃、已归档和全部合并为一个有明确无障碍名称的筛选框；刷新使用有标签的图标按钮。
- 对话按置顶、最近对话分组。置顶遵循 `pinOrder`，最近列表保留服务端顺序，两个组都可折叠。标题占满行宽，过长时省略并保留完整标题提示；选中行使用中性色背景。
- 顶部入口和底部管理、语言固定，只有历史列表滚动。管理菜单按需打开，可用页面直接列出，未启用页面集中在可展开区域，仍可进入查看部署说明。
- 顶栏显示当前对话标题与连接、外观、详情入口。路由切换继续将读屏焦点移至标题，但不为非交互标题绘制输入框式描边。交互控件保留键盘焦点提示。
- 未选择对话时展示开始工作的提示及新建入口。创建对话、搜索、审批、模型和数据权限沿用原有产品合同。

## 验收

1. 新建、搜索、选择对话与归档筛选可操作；置顶项不会在最近列表重复出现。
2. 管理菜单可以进入已安装页面，未安装功能仍保留说明入口；导航后菜单关闭，Escape 可关闭菜单并回到菜单按钮。
3. 桌面收起后可恢复侧栏；长列表不挤掉顶部和底部入口；手机宽度无横向溢出。
4. 中、英、日三种界面语言可用；正常键盘焦点可见，程序聚焦标题不出现整行边框。
5. 原始设计文件不被覆盖；本地界面测试不作为 Hermes 发布成功的证据。

## 验证方式

使用侧栏组件测试检查分组、排序、链接与空列表入口，运行浏览器测试、类型检查、构建及边界检查。使用隔离的浏览器测试服务实际操作桌面和手机视口；该服务提供固定对话与模型边界，不调用真实模型或读写生产数据。Hermes 部署及公网验收单独报告。
