取法：main 和各远程分支上 `.agents/reviews/pr-*/` 的 `usage.jsonl` 和 `verdicts.jsonl`，按 PR 目录、时间、模型、轮次去重。

- PR 数：180 个 PR 的复核记录。
- 成立的意见按类：中高 904 条、低 2058 条、可以更好 868 条、不成立 618 条。

- 有第 1 轮记录的 168 个 PR 里，135 个第 1 轮就有中高意见。

- 改动前增量轮的提示原话：“上一轮复核到 ${previous}，先看 git diff ${previous}..${head} 的增量，但可以读任何文件。”。增量轮的步数和费用与第 1 轮几乎一样，说明模型每轮基本把整个 PR 重查一遍。

## Claude 线程的用量（仓库外，来自线程记录）

抽查 4 个 PR 线程的会话记录，按 API 价折算：

- 4 个 PR 的整个线程 39–86 美元；同一批 PR 的 DeepSeek 复核 0.39–1.44 美元。
