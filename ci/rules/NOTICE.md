# Himawari 自有安全规则

本目录的 Semgrep 规则与 Gitleaks 调用配置由本项目为 GitHub CI 原创编写，未复制第三方规则内容。
这些自有文件与本仓库其他自有代码适用相同的权利与许可安排；本说明不另外授予 MIT
或其他通用开源许可，也不改变仓库的许可策略。

Gitleaks 的默认规则随已锁定的 Gitleaks 发行物提供，其上游许可证据独立记录在
`ci/toolchain-lock.json`。Semgrep 引擎的上游许可也独立记录，不能用本文件替代。

本目录的规则、正反样例和说明通过工具链锁中的摘要整体固定。修改规则后必须重新运行
正反样例，扫描器不得自行获取远程或浮动规则。
